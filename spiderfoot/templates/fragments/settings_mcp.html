Agent (MCP)

Lets an agent list modules, build and run scans, and read their results over the Model Context Protocol. It runs on its own port and needs an access token. It never exposes API keys or settings.

{# ------------------------------------------------------------ Status + switch #}

Enable agent access

Generate a token first.

{# ------------------------------------------------------------ Token #}

Access token

No token yet. Agents cannot connect until you generate one.

Current token . Only a fingerprint is stored, so the token cannot be shown again.

{# One-time reveal #}

Copy this token now. It cannot be shown again.

Rotating signs out every agent using the current token, immediately. The new token has to be given to them.

Revoking deletes the token and switches agent access off. Agents lose access immediately.

{# ------------------------------------------------------------ Permissions #}

What an agent may do

Reading modules, scans and results is always allowed with a valid token.

{# ------------------------------------------------------------ Connect #}

Connect an agent

Add this to the MCP client configuration and replace <your token> with the token. The port is unknown until SF_MCP_PORT is set.
