Agent (MCP)

Lets an agent list modules, build and run scans, and read their results over the Model Context Protocol. It runs on its own port and acts as you: it sees and changes the same scans you can, and nothing else. It never exposes API keys or settings.

{# ------------------------------------------------------------ Status + switch #}

Enable agent access

For everyone. Users create their own tokens below.

{# ------------------------------------------------------------ Tokens #}

Your access tokens

A token lets an agent act as you. It has your access at the time it is used: if your groups change, so does what it can do. Only a fingerprint is stored, so a token cannot be shown again. Agents that can sign in through your identity provider can also present their SSO access token instead.

{# One-time reveal #}

Copy this token now. It cannot be shown again.

You have no tokens yet.

{# ------------------------------------------------------------ Permissions #}

What an agent may do

These limits are set by an administrator and apply to every agent. Within them, an agent can only touch the scans you can: view lets it read, edit lets it stop and rerun, and only the owner of a scan can delete it.

{# ------------------------------------------------------------ Connect #}

Connect an agent

Add this to the MCP client configuration and replace <your token> with one of your tokens. The port is unknown until SF_MCP_PORT is set.
