Reports

When a scan has finished, the AI assistant can write a full report of it: an executive summary, the identity assessment, findings by category, risks, limitations and next steps, with a numbered appendix of the findings it cites. The report is built from computed summaries of the scan, one short prompt per section, so it works with small local models. Without a working AI endpoint a report of figures and lists is written instead. Reports use the connection, model list and “mask personal data” switch of Settings → AI Assistant.

The AI assistant is off or not configured: automatic reports are not written, and a report you ask for contains figures and lists only.

Limits

Each part of a report is one call. A report stops using the AI endpoint when it reaches either limit and finishes the remaining parts without it. Token counts are the endpoint’s own figures, which can include a prompt the server adds to every call.
