Web Search

Web searches (the SearXNG module, Pastebin, Onion.link, social profile finder) run on your own SearXNG metasearch instance, so no search-engine API key is needed. Optionally an OpenAI-compatible embeddings endpoint ranks phrase-search results by how well they match the scan target.

Embeddings (optional)

An OpenAI-compatible /embeddings API (Ollama, llama.cpp, vLLM, llama-swap, OpenAI...). Phrase-search results are ranked by similarity to the scan target and weak matches are dropped. Leave the URL empty to skip ranking.
